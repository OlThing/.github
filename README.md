# OlThing organization profile

This repository contains the public [OlThing organization overview](profile/README.md).

- Edit `profile/README.md` to update the organization page.
- The current architecture image is `profile/assets/olthing-architecture.svg`. Edit the SVG directly; it has no external fonts, scripts, or image dependencies. Keep its date, status legend, and README explanations in sync with the implementation evidence.
- `profile/assets/olthing-system-architecture.drawio` and its PNG are earlier architecture drafts, kept for reference. They are not displayed in the current overview because their offline, remote push, and AWS service assumptions need review against the latest policies.
- Detailed product requirements live in the team’s [docs repository](https://github.com/OlThing/docs).
