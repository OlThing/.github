# OlThing organization profile

This repository contains the public [OlThing organization overview](profile/README.md) and its architecture diagram.

- Edit `profile/README.md` to update the organization page.
- Edit `profile/assets/olthing-system-architecture.drawio` to update the diagram, then export the matching PNG.
- Detailed product requirements live in the team’s [docs repository](https://github.com/OlThing/docs).
